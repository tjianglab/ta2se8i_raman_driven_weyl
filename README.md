# Data and scripts for CDW gap collapse and Weyl state restoration in (TaSe4)2I

Data and scripts to generate the figures in:

T. Jiang, J. Wang, Y.-X. Yao, "CDW gap collapse and Weyl state restoration in Ta2Se8I via coherent phonons: a first-principles study", npj Computational Materials (2026), https://doi.org/10.1038/s41524-026-02391-5 (arXiv:2602.07897).

## Contents

| Folder | Description |
|---|---|
| FIG_01 | Structure and Ta-chain modulation under the CDW amplitude mode A(18) |
| FIG_02 | Gap suppression and Weyl nodes under A(18) |
| FIG_03 | Other Raman-active modes |
| FIG_04 | Nonlinear coupling between B3(7) and A(18) |
| FIG_A1–A3 | Additional figures |
| FIG_S_PBEsol_validation | PBEsol validation (Supplementary) |
| FIG_S_local_weyl_DFT | Direct DFT check near Weyl nodes (Supplementary) |
| FIG_S_phonon_dispersion | Full phonon dispersion (Supplementary) |
| FIG_S_rectified | Rectified A(18) response (Supplementary) |
