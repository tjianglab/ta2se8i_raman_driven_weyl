# Data and scripts for CDW gap collapse and Weyl state restoration in (TaSe4)2I

Data and scripts to generate the figures in:

T. Jiang, J. Wang, Y.-X. Yao, "CDW gap collapse and Weyl state restoration in Ta2Se8I via coherent phonons: a first-principles study", npj Computational Materials (2026), https://doi.org/10.1038/s41524-026-02391-5. Preprint: https://arxiv.org/abs/2602.07897

## Contents

| Folder | Description | Paper figure |
|---|---|---|
| FIG_01 | Structure and Ta-chain modulation under the CDW amplitude mode A(18) | Fig. 1 |
| FIG_02 | Gap suppression and Weyl nodes under A(18) | Fig. 2 |
| FIG_03 | Other Raman-active modes | Fig. 3 |
| FIG_04 | Nonlinear coupling between B3(7) and A(18) | Fig. 4 |
| FIG_S1_gap_collapse_paths | Direct-gap collapse on different high-symmetry paths | Supplementary Fig. S1 |
| FIG_S2_element_resolved_bands | Element-resolved weights of the Γ–Z bands | Supplementary Fig. S2 |
| FIG_S3_A18_Ta_Se_decomposition | Ta-only and Se-only decomposition of A(18) | Supplementary Fig. S3 |
| FIG_S4_wannier_validation | Wannier vs. DFT band comparison (inputs, data, plotting script) | Supplementary Fig. S4 |
| FIG_S5_local_weyl_DFT | Direct DFT check near Weyl nodes | Supplementary Fig. S5 |
| FIG_S6_rectified | Rectified A(18) response induced by B3(7) | Supplementary Fig. S6 |
| FIG_S7_phonon_dispersion | Full phonon dispersion | Supplementary Fig. S7 |
| FIG_S8_PBEsol_validation | PBEsol validation | Supplementary Fig. S8 |
